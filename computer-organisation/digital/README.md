**直接可用的结论：** 用 Digital 打开本目录里的 `.dig` 文件即可批改/演示。

| 习题 | 文件 | 功能 | 已内置测试 |
| --- | --- | --- | --- |
| 积木 | `HalfAdder.dig` | 半加器 \(S=A\oplus B,\ C=A\land B\) | 4 组，全部通过 |

## 1. 怎么在 Digital 里打开和跑测试

1. 启动 Digital（`Digital.exe` / `Digital.jar`）。
2. **File → Open**，先开 `Successor4.dig` 或 `Negation3.dig`。
3. 点绿色 **Start**（开始仿真）：左边输入是开关，点一下翻转 0/1；右边输出会跟着变。
4. 画布上绿色 **Test** 方块：
   - 右键 → **Start tests**（或菜单里的测试），应显示 *passed*。
   - 双击 Test 可查看/编辑真值表。

命令行（与本仓库验证方式相同，Windows / Linux 都可用）：

```bat
java -cp Digital.jar CLI test -circ Successor4.dig
java -cp Digital.jar CLI test -circ Negation3.dig
java -cp Digital.jar CLI test -circ HalfAdder.dig
```

同目录下的 `run-tests.sh` 会依次跑三个测试。需要先设 `DIGITAL_JAR` 指向 `Digital.jar`。

## 2. 第一性原理：后继就是「加 1」

二进制加 1 只有两种局部规则：

- 遇到 `0`：变成 `1`，进位结束。
- 遇到 `1`：变成 `0`，进位继续向高位走。

这恰好是半加器：本位 \(S_i=A_i\oplus C_{i-1}\)，进位 \(C_i=A_i\land C_{i-1}\)。最低位的「加数」恒为 1，所以再化简一次（奥卡姆剃刀）：

\[
S_0=\overline{A_0},\qquad C_0=A_0
\]

高 3 位用半加器把进位一级一级 Ripple 上去。**「完整 / full」** 的含义：保留最高位进位 \(C_{out}\)，因此 `1111 + 1 = 1_0000`，而不是悄悄溢出成 `0000`。

### 习题 1 真值表（16 组全覆盖）

输入按 \(A_3A_2A_1A_0\)，输出按 \(C_{out}\,S_3S_2S_1S_0\)（5 位）。

| \(A\) | 十进制 | \(A+1\) | 说明 |
| ---: | ---: | ---: | --- |
| 0000 | 0 | 0 0001 | |
| 0001 | 1 | 0 0010 | |
| 0010 | 2 | 0 0011 | |
| 0011 | 3 | 0 0100 | |
| 0100 | 4 | 0 0101 | |
| 0101 | 5 | 0 0110 | |
| 0110 | 6 | 0 0111 | |
| 0111 | 7 | 0 1000 | |
| 1000 | 8 | 0 1001 | |
| 1001 | 9 | 0 1010 | |

电路结构（从低到高）：

```
A0 ── NOT ── S0
 │
 └── C0 ──┐
A1 ────── HA1 ── S1
           └── C1 ──┐
A2 ────────────── HA2 ── S2
                    └── C2 ──┐
A3 ────────────────────── HA3 ── S3
                              └── C_out
```

## 3. 第一性原理：取负就是「按位取反再加 1」

补码定义：\(-x=\overline{x}+1\)。  
1 位取负（提示里的「类似于 1-bit negation」）是同一条规则，只是宽度更小：

| 无符号 \(x\)（1 位） | 零扩展到 2 位 | 取反 | +1 | 得到的 \(-x\) |
| ---: | ---: | ---: | ---: | ---: |
| 0 | 00 | 11 | 100 → **00** | 0 |
| 1 | 01 | 10 | **11** | -1 |

习题 2 只是把宽度改成「3 位正数 → 4 位负数」：

1. 把 \(X_2X_1X_0\) **高位补 0**，变成 4 位 \(0\,X_2X_1X_0\)。
2. **4 位全部取反**（常数 0 也要取反，得到最高位 1）。
3. 把结果送进习题 1 的 4 位后继器，完成 `+1`。

因此 `Negation3.dig` **必须和 `Successor4.dig` 放在一起**。后继器的 \(C_{out}\) 在取负电路里故意不引出：  
\(X=0\) 时 \(\overline{0000}+1=10000\)，留下低 4 位 `0000` 正好是 \(-0\)。

### 习题 2 真值表（8 组全覆盖）

| \(X_2X_1X_0\) | 十进制 \(X\) | 零扩展 | 取反 | +1 后的 \(Y_3Y_2Y_1Y_0\) | 含义 |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 000 | 0 | 0000 | 1111 | **0000** | 0 |
| 001 | 1 | 0001 | 1110 | **1111** | -1 |
| 010 | 2 | 0010 | 1101 | **1110** | -2 |
| 011 | 3 | 0011 | 1100 | **1101** | -3 |
| 100 | 4 | 0100 | 1011 | **1100** | -4 |
| 101 | 5 | 0101 | 1010 | **1011** | -5 |
| 110 | 6 | 0110 | 1001 | **1010** | -6 |
| 111 | 7 | 0111 | 1000 | **1001** | -7 |

课堂抽查建议：先拨 `001` 看是否得到 `1111`，再拨 `111` 看是否得到 `1001`。

## 4. 文件说明

| 文件 | 用途 |
| --- | --- |
| `HalfAdder.dig` | 可复用半加器；也可单独打开讲 XOR/AND |
| `Successor4.dig` | 习题 1 答案，已设为子电路外形 `+1` |

| `run-tests.sh` | 一键跑 CLI 测试 |
| `_generate.py` | 如需改坐标可重新生成 `.dig`（一般不用） |
| `preview/*.svg` | 电路预览图，不依赖 Digital 也能看结构 |

仿真时输入默认：后继器 \(A_0=1\)（即从 1 开始），取负器 \(X_0=1\)（即演示 -1 = 1111）。
